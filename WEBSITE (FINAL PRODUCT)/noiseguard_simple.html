How NoiseGuard works

A compact view of the pipeline.

01 · PGD

Projected Gradient Descent searches for a small adversarial perturbation while keeping the image inside a fixed epsilon budget.

02 · MIRAGE

The second optimization stage further modifies the protected image toward the project's surrogate objective and projects the final result back into the original budget.

03 · Output

The browser sends the image to the Python API and displays the returned protected image and metrics.

04 · Prototype

This is a research/student prototype. Images are processed by the configured backend; storage and deletion depend on the backend implementation.
